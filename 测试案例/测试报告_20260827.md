## 1. 本轮缺陷与修复

| 问题 | 原因 | 修复 |
|------|------|------|
| **DB-06** 无效分享仍像正常看板 | `ShareView.vue` 请求 404 未 catch，默认标题「分享看板」+ 空结论占位 | 捕获失败后展示「分享链接无效或已失效」，不渲染 KPI/图表 |
| **ST-03** 无法选文本指标 | Y 下拉只列出数值列，与用例「可选文本列后 400」不一致 | Y 下拉列出全部字段，标签区分「数值/文本」；选「平台（文本）」生成仍失败且右侧不出图 |
| 看板图表经常只渲染 1 张 | `ChartPanel` 懒加载依赖 IntersectionObserver，网格内偶发不触发 | 400ms 超时后强制 `ready`；复测看板可见 **4** 个 canvas |
| pytest `test_upload_sample_csv_and_excel` | `sample_data` 缺失；列名为中文而断言写死英文 | 从 `测试数据` 恢复样例；断言同时接受中英文列名 |
| AI-02 无 Key 规则引擎 | 线上有 DeepSeek Key，不便关 Key 测 UI | 新增 `test_recommend_rules_without_llm`，`source=rules` |
