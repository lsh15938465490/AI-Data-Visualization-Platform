# AI 驱动的数据可视化与智能分析平台需求说明书

> 本文档依据仓库 **当前已实现代码** 整理，作为功能基线说明。  
> 测试同事请同时阅读同目录 **`测试需求规格与用例大纲.md`**（含优先级、步骤、期望与冒烟清单）。  
> 版本日期：2026-08-27  
> 前端技术约束：**Vue 3**（不使用 React）。

---

## 1. 产品定位

面向业务运营人员的数据分析工具：上传 CSV / Excel / JSON 表格后，可通过手动配置或自然语言完成聚合出图，输出结构化「分析结论」，并在可拖拽仪表盘中做联动筛选、公开分享与导出。

适用于数据产品、BI、AIGC 数据面板相关岗位演示与实习项目展示。

**分析主路径（已实现）：**

自然语言 / 手动配置 → 解析为可校验的图表配置（图类型、维度、指标、聚合）→ pandas 分组聚合 → ECharts 渲染；洞察与推荐先做数据特征画像，配置了大模型密钥则调用 Chat Completions，否则回退本地规则。

**明确未实现（避免与代码不符）：**

- 用户注册、HTTP API 拉数接入
- 向量模型 / Embedding / RAG
- AI 生成 Python 代码并沙箱执行（无 `code_executor`）
- matplotlib / seaborn 服务端出图

## 2. 技术栈

| 层次 | 技术 |
|------|------|
| 前端 | Vue 3、Vite、TypeScript、Pinia、Vue Router、Element Plus、ECharts 5、vue-echarts、grid-layout-plus、html2canvas、jspdf |

## 4. 信息架构与页面

登录后侧栏：数据集、AI 问答、图表工作室、仪表盘。

| 路由 | 页面 | 职责 |
|------|------|------|
| `/login` | 登录 | 账号密码登录 |
| `/datasets` | 数据集 | 上传、列表、预览、删除、跳转问答/做图 |
| `/ask` | AI 自然语言问答 | 选数据集、快捷问题、提问出图与结论、可选保存图表 |
| `/studio` | 图表工作室 | 手动配置出图、智能推荐、对话式分析、导出 PNG |
| `/dashboards` | 仪表盘列表 | 新建看板、从数据集一键生成、删除 |
| `/dashboards/:id` | 仪表盘详情 | KPI、分析结论、拖拽布局、联动筛选、分享、导出 PDF |
| `/share/:token` | 公开分享 | 未登录只读查看看板 |

布局：`html/body/#app` 锁定视口高度，内容在 `el-main` 内滚动，避免整页与图表区双重滚动冲突。

## 5. 功能需求

### 5.1 数据集（文件上传）

- 仅支持 **本地文件上传**（已去掉「接入 API / from-api」）。
- 识别格式 **按文件内容嗅探**，不依赖后缀名：
  - Excel：xlsx（ZIP + `xl/`）、xls（OLE 头）
  - JSON：对象或数组（可识别常见 `data` / `items` 等路径）
  - CSV：文本 + 逗号/制表符分隔
- 同一用户下 **文件名不可重复**；重复时后端 409，前端弹窗提示。
- 列表展示名称、文件名、行数、字段；支持预览（默认约 50 行）、删除。
- 删除需 **二次确认**；删除数据集同时删除关联图表及上传文件。

测试数据：

- `backend/sample_data/sales.csv`：字段为 `英文（中文）`，如 region（地区）、sales（销售额）
- `backend/sample_data/ad_campaign（广告投放）.xlsx`：字段为 `英文（中文）`，如 platform（平台）、impressions（曝光量）

对应接口：`POST /api/datasets/upload`，`GET /api/datasets`，`GET /api/datasets/{id}`，`GET /api/datasets/{id}/preview`，`DELETE /api/datasets/{id}`。

### 5.2 图表工作室（手动配置）

用户选择数据集后配置：

- 标题
- 图表类型：柱状图、折线图、饼图、散点图
- 维度 X、指标 Y（Y 须为数值列；文本列做 sum/mean 等会报错提示）
- 聚合：求和、平均、计数、最大、最小  

**聚合求和含义：** 按 X 字段分组，将组内 Y 值相加后画图（同一日期多平台曝光会加总成一根柱）。

「生成并保存」调用 `POST /api/charts`，右侧预览 ECharts，并刷新分析结论区。

工作室对话区：

- 输入为空点「发送」时，使用示例句：**帮我分析近三个月销售额趋势**
- 发送后对话列表 **自动滚到底部**
- 支持自然语言出图，以及微调：标题、主色（蓝/红/绿/橙/紫/青）、图例位置（顶/底/隐藏）
- 对话默认 **保存图表**（`save: true`）

单图可导出 PNG（html2canvas）。

### 5.3 AI 自然语言问答

独立入口 `/ask`，数据集列表「AI 问答」可带 `datasetId` 跳转。

- 进入时拉取推荐：展示 KPI 卡片（行数、指标合计/均值、主导分类等）及数据集级结论
- 快捷标签提问或自由输入
- 可选「同时保存图表」
- 右侧：图表 + 「分析结论」分区 + 异常告警条

接口：`POST /api/ai/analyze`。

### 5.4 智能推荐与分析结论

**推荐（`GET /api/ai/recommend`）：**

1. 抽取数据特征：行数、列类型、空值率、唯一值、数值 min/max/mean/sum、类别 Top 值
2. 若配置大模型密钥：将特征 JSON 发给模型，返回推荐图表列表 + 结论（字段必须落在真实列名内，后端会校验）
3. 无密钥或解析失败：规则推荐（时间+指标→折线，维度+指标→柱状/饼，双数值→散点）

**分析结论（独立 UI 区域，与聊天回复区分）：**

- 图表级：分组数、合计、均值、最高/最低贡献、头部集中度、末段环比、空值提示
- 有密钥时由大模型按汇总样本改写（约 220 字内、分条）
- 界面标签：大模型 / 特征规则

**健康检查：** `GET /api/health` 返回 `llm`：`deepseek` | `openai` | `none`。

### 5.5 大模型配置（DeepSeek 优先）

后端工作目录 `.env`（示例见 `backend/.env.example`）：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
```

密钥变量名兼容：`DEEPSEEK_API_KEY`、`DEEPSEEK_KEY_API`、`deepseek_key_api`。

未配 DeepSeek 时可用 `OPENAI_API_KEY` + `OPENAI_BASE_URL` + `OPENAI_MODEL` 走其它 OpenAI 兼容接口。修改环境变量后需重启后端。

调用方式：`POST {base}/chat/completions`，不使用 embedding 接口。

### 5.6 仪表盘

- **新建：** 选择已有图表组成看板
- **从数据集一键生成：** `POST /api/dashboards/from-dataset`，按推荐批量建图，专业布局（首图通栏），写入 KPI 与看板级结论
- 详情页：经营看板头图、KPI、分析结论、图表卡片（类型标签：趋势/对比/占比/相关）
- 拖拽、缩放布局并保存
- **联动：** 点击某分类/日期，其它图按同一维度过滤
- **分享：** 生成 token，复制 `/share/{token}`；`GET /api/public/dashboards/{token}` 公开只读
- 仪表盘导出 PDF；列表删除需确认

其它接口：`GET/POST/PUT/DELETE /api/dashboards`，`POST /api/dashboards/{id}/share`。

### 5.7 异常告警

分析或对话出图后，对聚合序列做 z-score；绝对值 ≥ 1.5 视为偏离。通过 WebSocket 推送到前端，登录布局内 `ElNotification` 提示。

连接：`ws://{host}/api/ws/alerts?token={JWT}`（开发环境经 Vite 代理）。

### 5.8 渲染与性能

- 分类超过 12 个时启用 dataZoom
- 系列 `progressive` 渐进渲染
- Worker：`frontend/src/workers/downsample.ts` 对超长序列降采样
- 仪表盘 / 分享页图表 `lazy`：进入视口后再初始化 ECharts

## 7. 非功能需求

- 业务数据按 `owner_id` 隔离；分享接口不校验登录，仅凭 token 只读
- 上传文件落在 `backend/uploads/`，SQLite 默认 `backend/data.db`
- CORS 默认包含本地 Vite 端口；前端一律经 `/api` 访问后端
- 自动化测试：`backend` 目录执行 `pytest`（含上传嗅探、重复文件名、对话改色、分享、DeepSeek 环境变量别名、一键看板等）

## 8. 验收要点（对照实现）

1. 仅登录、无注册；演示账号可进入系统  
2. 上传 CSV/Excel（含「假后缀」按内容识别）；重名弹窗；删除二次确认  
3. 工作室手动聚合出图；空输入发送走示例问句；对话区滚到底  
4. AI 问答与分析结论分区可见；无密钥为规则结论，有 DeepSeek 密钥后 `health.llm=deepseek`  
5. 一键生成看板含 KPI 与多图；点击维度联动；分享链接未登录可打开  
6. 异常可弹通知；图表 PNG、看板 PDF 可导出
