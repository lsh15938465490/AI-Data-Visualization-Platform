# AI 驱动的数据可视化与智能分析平台需求说明书

## 1. 产品定位

面向业务运营人员的数据分析工具：支持 CSV / Excel 文件上传，通过自然语言对话生成图表与洞察，并在可拖拽仪表盘中联动筛选、分享与导出。适用于数据产品、BI、AIGC 数据面板相关岗位展示。

前端保持 **Vue 3**（非 React）。

## 2. 技术栈

- 前端：Vue 3、Vite、TypeScript、Pinia、Vue Router、Element Plus、ECharts 5、grid-layout-plus、Web Worker、WebSocket
- 后端：FastAPI、SQLAlchemy、SQLite、pandas、WebSocket
- AI：规则引擎 + 可选 OpenAI 兼容接口

## 3. 账号与登录

- 仅登录，不提供注册
- 演示账号：`alice` / `secret123`

## 4. 功能范围

### 4.1 多数据源

- 上传 CSV / Excel / JSON（按文件内容识别格式，不依赖后缀名）
- 同一用户下文件名不可重复，重复时弹窗提示
- 列表、预览、删除

测试数据：

- `backend/sample_data/sales.csv`：字段为 `英文（中文）`，如 region（地区）、sales（销售额）
- `backend/sample_data/ad_campaign（广告投放）.xlsx`：字段为 `英文（中文）`，如 platform（平台）、impressions（曝光量）

### 4.2 对话式图表生成

- 自然语言问答入口：侧栏「AI 问答」、数据集列表可直达
- 先抽取数据特征（类型、空值、分布），再调用大模型 API 推荐图表；无密钥时回退规则引擎
- 分析结论独立展示区
- 自然语言 → 聚合查询 → ECharts 配置
- 对话微调标题、主色、图例位置
- 工作室可手动配置并保存

### 4.3 仪表盘构建器

- 从数据集一键生成含 KPI、趋势与结构图的专业看板
- 拖拽、缩放多图表布局并保存为模板
- 点击某分类/日期，关联图表按同一维度过滤
- 生成分享链接，未登录可查看公开看板

### 4.4 智能洞察与告警

- 自动解读并输出「分析结论」（最高分组、合计、集中度、末段变化）
- 指标偏离均值时检测异常，并通过 WebSocket 推送到前端
- 单图导出 PNG，仪表盘导出 PDF

### 4.5 渲染优化

- 分类较多时启用 ECharts dataZoom
- 系列渐进式渲染
- Web Worker 对超长序列降采样
- 仪表盘图表进入视口后再渲染（懒加载）

## 5. 非功能要求

- 业务接口校验 JWT；分享接口公开只读
- 前端 `/api` 代理含 WebSocket
