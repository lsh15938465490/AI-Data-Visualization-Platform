# 测试需求规格与用例大纲

> 面向对象：测试同事编写测试用例、执行冒烟与回归。  
> 依据：当前仓库已实现功能（与 `需求说明书.md` 一致）。  
> 版本：2026-08-27  
> 前端：Vue 3 应用，默认开发地址 `http://localhost:5173`（若端口占用则为 5174/5175），接口经 `/api` 代理到后端 `http://127.0.0.1:8001`。

本文给出 **测试范围、前置条件、需求点、建议用例编号、步骤与期望**。测试同事可直接拆成禅道/Excel 用例，建议保留本文编号作为需求追溯。

## 0. 测试说明

### 0.1 优先级

| 级别 | 含义 | 不通过影响 |
|------|------|------------|
| P0 | 冒烟 / 主路径 | 无法演示或核心流程中断 |
| P1 | 重要功能与校验 | 体验或数据错误，必须修 |
| P2 | 体验、边界、性能 | 可排期 |

### 0.2 环境与账号

| 项 | 值 |
|----|----|
| 演示账号 | `alice` / `secret123`（登录页有展示，仅登录无注册） |
| 健康检查 | `GET http://127.0.0.1:8001/api/health`，JSON 含 `status=ok`、`llm`（`none` / `deepseek` / `openai`） |
| 大模型 | 密钥仅在服务器/本机 `backend/.env`，**不要**用测试账号把真实 Key 写进用例附件或 Git |
| 有密钥 | `llm=deepseek` 或 `openai`，结论区标签为「大模型」，耗时可能 3～20 秒 |
| 无密钥 | `llm=none`，结论区标签为「特征规则」，仍应能出图和结论 |

**分组建议：** 用例分为「规则引擎（无 Key）」与「大模型（有 Key）」两套；P0 必须在无 Key 下也能通过。

### 0.3 标准测试数据（仓库内）

| 文件 | 路径 | 要点 |
|------|------|------|
| 销售 CSV | `backend/sample_data/sales.csv` | 约 24 行、7 列；字段如 `region（地区）`、`sales（销售额）`；华南销售额合计约 7441300，全表销售额合计 10113330 |
| 广告 Excel | `backend/sample_data/ad_campaign（广告投放）.xlsx` | 15 行、8 列；同一天 3 个平台；按日期对曝光量**求和**时：03-01=597200，03-03=943500，03-04=508100 |

自备数据建议：另存一份改后缀的 CSV（如 `sales.txt`）、一份二进制乱码改名为 `.csv`、一份与已上传**同名**的文件。

### 0.4 不在测试范围（勿当缺陷）

- 注册、找回密码、多用户权限体系（目前仅演示用户）
- 「接入 API / from-api」拉数（已下线）
- 向量检索、RAG、AI 生成 Python 再执行
- 一次选择多个文件上传（当前为单文件）
- 真实 Key 出现在前端页面或接口响应明文（密钥只在后端）

### 0.5 缺陷判定原则

- 与本文「期望结果」不符 → 缺陷  
- 大模型措辞每次不同，但须：**中文、与当前数据集相关、分析结论区有内容、图表有 series**；不要求字字相同  
- 未配置 Key 时走规则结论，**不是**缺陷

## 1. 登录与导航

### 需求

- 未登录访问业务页跳转 `/login`
- 正确账号进入数据集页；错误密码提示「用户名或密码错误」
- 无注册入口；访问 `/register` 回到登录
- 登录后侧栏：数据集、AI 问答、图表工作室、仪表盘
- 右上角显示 `alice`，退出后回登录页
- `/share/:token` 可不登录访问（见第 6 章）

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| AUTH-01 | 正确登录 | P0 | 打开站点 → 用 alice/secret123 登录 | 进入 `/datasets`，侧栏四项可见 |
| AUTH-02 | 错误密码 | P1 | 密码改为错误值提交 | 停留登录页，有错误提示，无 token |
| AUTH-03 | 未登录拦截 | P0 | 无登录态直接打开 `/studio` | 跳转 `/login` |
| AUTH-04 | 无注册 | P1 | 打开 `/register` | 重定向到登录，无注册表单 |
| AUTH-05 | 退出 | P1 | 登录后点退出 | 回登录页，再访 `/datasets` 需重新登录 |
| AUTH-06 | 登录页展示账号 | P2 | 打开登录页 | 可见演示账号与密码文案 |

## 2. 数据集上传、预览、删除

### 需求要点

- 仅「上传 CSV / Excel」，无「接入 API」
- **按文件内容识别**，不按后缀：真 CSV 即使叫 `.txt` 应成功；二进制改名为 `.csv` 应失败（400，提示无法识别）
- 同一用户 **文件名重复**：前端弹窗「文件名重复」，后端 409
- 列表列：名称、文件名、行数、字段；无「来源」列
- 预览弹窗展示列与行（最多约 50 行）
- 删除：**二次确认**；取消不删；确定后列表消失，关联图表一并删除
- 操作：预览、AI 问答、做图、删除

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| DS-01 | 上传销售 CSV | P0 | 上传 `sales.csv` | 成功提示；行数 24；字段含地区/销售额中英文名 |
| DS-02 | 上传广告 Excel | P0 | 上传 `ad_campaign（广告投放）.xlsx` | 行数 15；字段含 platform（平台）、impressions（曝光量） |
| DS-03 | 内容识别-假后缀 | P0 | 将 CSV 另存为 `xxx.txt` 上传 | 上传成功，可预览 |
| DS-04 | 内容识别-假 CSV | P1 | 将乱码/二进制文件改名为 `a.csv` 上传 | 失败提示无法识别为表格 |
| DS-05 | 文件名重复-前端 | P0 | 同一文件再上传一次 | 弹窗「已上传过」，列表不新增一条 |
| DS-06 | 预览 | P0 | 点预览 | 弹窗有表头与数据行 |
| DS-07 | 跳转问答 | P1 | 点「AI 问答」 | 进入 `/ask`，下拉框选中该数据集 |
| DS-08 | 跳转做图 | P1 | 点「做图」 | 进入 `/studio` 且带上该数据集 |
| DS-09 | 删除取消 | P1 | 点删除 → 取消 | 记录仍在 |
| DS-10 | 删除确认 | P0 | 点删除 → 确定删除 | 成功提示，列表无该文件；工作室无法再选该集 |
| DS-11 | 未登录上传 | P1 | 清 token 调 `POST /api/datasets/upload` | 401 |

**聚合对照（广告数据，供出图用例引用）：**  
X=日期、Y=曝光量、聚合=求和时，柱高应对应该日三平台曝光之和，而不是单条 520000。

## 3. 图表工作室

### 需求要点

- 配置：标题、类型（柱/折/饼/散点）、维度 X、指标 Y、聚合（求和/平均/计数/最大/最小）
- Y 轴选项仅为数值列；对文本列做求和应 **400**，提示改选数值指标
- 「生成并保存」：右侧出图，图表写入库
- 智能推荐：标签可点击，回填类型/X/Y/聚合
- 对话式分析：
  - 输入框为空为 **灰色占位**「例如：帮我分析近三个月销售额趋势；…」
  - 自己输入后为 **深色**
  - 空内容点发送：按示例第一句 **帮我分析近三个月销售额趋势** 提问，输入框仍为空（占位还在）
  - 对话区滚动条在发送后滚到最底
- 可改颜色（橙/蓝等）、标题、图例位置；图表即时变
- 对话默认保存图表
- 分析结论独立区域；可能有异常黄条
- 导出 PNG 下载图片

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| ST-01 | 手动柱状求和 | P0 | 选广告集，X=日期，Y=曝光量，聚合=求和，生成 | 约 5 根柱；03-03 明显高于 03-04 |
| ST-02 | 平均 vs 求和 | P1 | 同上改平均再生成 | 柱高约为求和的 1/3（每天 3 条） |
| ST-03 | 文本当指标 | P0 | Y 选平台等文本，求和生成 | 失败提示，不能当数值求和 |
| ST-04 | 四种图类型 | P1 | 分别选柱/折/饼/散点生成 | 均能渲染，无空白高为 0 |
| ST-05 | 点击推荐 | P1 | 点一条智能推荐 | 表单字段被改写，可再生成 |
| ST-06 | 空发送走示例 | P0 | 输入框不打字点发送 | 对话出现「帮我分析近三个月销售额趋势」；框仍灰色占位 |
| ST-07 | 输入颜色区分 | P1 | 空 / 输入「测试」 | 空为灰，输入为深色 |
| ST-08 | 对话滚底 | P1 | 连续发送多次 | 最新回复可见，滚动条在底部 |
| ST-09 | 改成橙色 | P0 | 发送「把颜色改成橙色」 | 回复确认改色，柱/线变橙 |
| ST-10 | 图例顶部 | P2 | 发送「图例放到顶部」 | 图例位置变化 |
| ST-11 | 导出 PNG | P1 | 有图后点导出图片 | 下载 png |
| ST-12 | 右侧预览高度 | P1 | 生成后不滚动整页 | 图在右侧卡片内完整显示（高度约 420px） |

## 4. AI 自然语言问答

### 需求要点

- 路由 `/ask`；顶栏选数据集
- 进入后右侧先有 KPI（行数、某指标合计/均值、主导分类）和数据集级结论
- 快捷芯片可一点即问
- 空内容点「提问」：使用 **哪个地区销售额最高？近几个月趋势如何？**；输入框保持空、灰色占位
- 勾选「同时保存图表」后提问，应提示已保存，可在工作室/新建看板中看到
- 左侧：对话在上，**输入框与提问按钮钉在卡片最底部**；点提问后对话滚到最新
- 右侧：图表 +「分析结论」分区 + 可能的异常告警
- 有 Key 时标签「大模型」，无 Key「特征规则」

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| ASK-01 | 进入即有 KPI | P0 | 登录后打开 AI 问答，选销售 | 行数 24；销售额合计 10113330 量级；有结论区 |
| ASK-02 | 空提问走示例 | P0 | 不输入点提问 | 对话用户句为「哪个地区销售额最高？…」；输入框仍空且灰色；右侧出图 |
| ASK-03 | 芯片提问 | P1 | 点「区域占比如何？」 | 对话出现该句，饼图或占比类图 |
| ASK-04 | 华南最高 | P0 | 对销售数据问地区谁最高 | 结论提到华南为最高（规则或模型均可） |
| ASK-05 | 保存图表 | P1 | 勾选同时保存再提问 | 成功提示；新建看板能选到新图 |
| ASK-06 | 输入钉底 | P0 | 多次提问使记录变长 | 输入框仍在左卡最下方，不必滚走才能提问 |
| ASK-07 | 对话滚底 | P1 | 多次提问 | 最新问答在可视区，滚动条靠下 |
| ASK-08 | 切换数据集 | P1 | 销售切到广告 | KPI/结论随数据集变化，行数变为 15 |
| ASK-09 | 有无 Key 标签 | P1 | 分别在 `llm=none` 与 `deepseek` 下提问 | 标签与 health 一致；都能出图 |

## 5. 智能推荐与分析结论

- 分析结论与聊天记录分区展示，结论为分条文字

### 建议用例

|------|------|------|------|------|
| AI-01 | recommend 结构 | P0 | 带 token 请求销售数据集 recommend | 200；有 recommendations 数组；features.row_count=24 |

## 6. 仪表盘、联动、分享、导出

### 需求要点

- 列表：新建；从数据集一键生成；打开；删除需确认
- 一键生成：选数据集 → 生成 → 进入详情；有 KPI、结论、多图；首图布局偏通栏（w=12）
- 详情：拖拽缩放，保存布局
- 点击某图分类/日期：出现筛选标签，其它图按该维度过滤；关闭标签恢复
- 生成分享链接并复制；隐身窗口打开 `/share/{token}` 无需登录，只读
- 导出 PDF
- 无效 token 公开接口 404

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| DB-01 | 新建空选图 | P1 | 新建标题+选至少一张已有图 | 列表出现，可打开 |
| DB-02 | 一键生成 | P0 | 仪表盘 → 从数据集一键生成 → 销售 | 跳转详情；有 KPI 与 ≥1 张图；有分析结论 |
| DB-03 | 联动筛选 | P0 | 详情点柱上「华南」 | 顶部筛选标签；其它图数据变化；关闭标签恢复 |
| DB-04 | 保存布局 | P1 | 拖动卡片后保存 | 刷新后位置保持 |
| DB-05 | 分享未登录 | P0 | 生成分享 → 退出或隐身打开链接 | 能看标题与图，无侧栏业务菜单 |
| DB-06 | 无效分享 | P1 | 打开 `/share/not-a-token` | 失败/空，不泄露其它看板 |
| DB-07 | 导出 PDF | P1 | 详情点导出 PDF | 下载 pdf |
| DB-08 | 删除看板 | P1 | 列表删除 → 确认 | 看板消失（图表库中图可能仍在） |
| DB-09 | 删除取消 | P2 | 删除 → 取消 | 看板仍在 |

## 7. 异常告警与 WebSocket

### 需求

- 聚合后分组数 ≥ 3，某点 \|z-score\| ≥ 1.5 产生异常
- 分析/对话后前端 `ElNotification`：「指标异常告警」
- 销售数据问区域销售时，华南合计偏离大，**常出现**告警（可用于 P0）
- WS：`/api/ws/alerts?token=`，无 token 应断开

### 建议用例

| 编号 | 标题 | 级别 | 步骤 | 期望 |
|------|------|------|------|------|
| AL-01 | 销售区域告警 | P1 | 问答「哪个地区销售额最高」 | 结论区或通知出现华南偏离类文案（若本次 z 未达 1.5 则记观察） |
| AL-02 | 无 token 的 WS | P2 | 无 token 连 ws | 连接被关闭 |
