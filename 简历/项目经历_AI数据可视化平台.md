## 四、功能模块（面试时可按这条线讲）

1. **数据集**  
   上传 CSV/Excel（按内容嗅探格式）、解析成功/失败、字段截断与 Tooltip、预览、跳转问答/做图。

2. **AI 问答**  
   选数据集、快捷提问填入输入框、KPI 指标说明、打字机式结论、出图后可下载图片 / 保存到图表库 / 复制报告。

3. **图表工作室**  
   手动选 X 维度、Y 指标、聚合方式；Y 轴仅展示可出图的数值列（计数时可含文本列）；智能推荐一键套用；对话式改图；预览不落库、生成并保存才入库。

4. **我的图表**  
   已保存图表卡片列表（来源数据集、缩略图）、编辑配置并回写、删除二次确认。

5. **仪表盘**  
   新建看板（勾选已保存图表）与「从数据集一键生成」两条路径；详情页 KPI、折叠结论、拖拽布局、全局时间/区域筛选、图表点击联动、分享与导出。

6. **工程与体验**  
   JWT 演示登录、侧栏信息架构、统一 Loading/Toast、异常 WebSocket 告警、公开分享页免登录只读。

## 五、简历措辞注意（加分 / 避坑）

**建议强调**

- 完整业务闭环：数据接入 → 分析出图 → 资产沉淀 → 看板消费。
- AI 不是「调一个接口就结束」：配置校验、pandas 聚合、规则降级、流式/打字机展示。
- B 端细节：空状态、错误提示、不可用字段不进下拉、未保存布局拦截、二次确认删除。

**不要写或少写**

- 「支持向量数据库 / RAG / Agent 写代码执行」——本仓库未实现。
- 「用户注册、对接外部 HTTP 数仓」——当前仅演示账号 + 本地文件。
- 把 DeepSeek 写成自研大模型。

**可量化时再量化（有截图再写）**

- 例如：一键生成可同时产出 3～4 张推荐图表并带分析结论。  
- 例如：仪表盘支持点击维度后全部图表按同一字段过滤。

## 六、面试 60 秒口述稿

这是一个面向运营分析的 AI 可视化平台。用户上传 CSV 或 Excel 后，既可以用自然语言提问出图，也可以在图表工作室里选维度、指标和聚合方式手动出图。图表会保存成资产，在「我的图表」里编辑删除，再拼到可拖拽仪表盘上，支持联动筛选、分享和导出。

技术上前端是 Vue 3 + TypeScript + ECharts，后端 FastAPI + pandas。自然语言会先落成可校验的图表配置再聚合，配了 DeepSeek 就走大模型，没配就用规则引擎，保证现场能演示。我重点做了出图主链路、图表资产和看板联动，以及字段类型校验、Loading 和错误提示这些 B 端体验。
